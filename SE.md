# Unit - 4 (Sofftware Testing)

## Definition
- Software Testing is a ultimate process to ensure the correctness of the software
- Testing is a process of executing the program with intent of finding errors

## Software Testing Life Cycle (STLC)

1. Requirements Analysis
2. Test Planing
3. Test Case Development
4. Test Environment Setup
5. Test Execution
6. Test Reporting
